# Security Policy

The **flatmesh-rs** project takes memory safety, alignment invariants, and parser robustness seriously. We appreciate the responsible disclosure of any vulnerabilities, undefined behavior, or memory corruption bugs discovered in the format or runtime.

## Supported Versions

| Version | Supported |
| :--- | :---: |
| `0.1.x` (`main` / `dev`) | :white_check_mark: |
| `< 0.1.0` | :x: |

---

## Reporting a Vulnerability

> [!IMPORTANT]
> **Please do not report security vulnerabilities or zero-copy memory safety flaws through public GitHub issues or discussions.**

Instead, please send an encrypted or direct disclosure report to the maintainers at `contact@ulquiorra.dev` or use GitHub's private vulnerability reporting feature on the repository.
